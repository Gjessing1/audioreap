Duplicate tracks

Tracks with the same MusicBrainz recording ID in multiple files. Shows a list — you choose which copy to keep. Nothing is deleted automatically.

Split albums

Albums that appear to be the same release stored in different folders (e.g. "The Beatles" vs "Beatles, The"). You approve every merge — nothing happens automatically.

yt-dlp

yt-dlp breaks when YouTube changes. Update to the latest version without restarting the container.

Missing cover art

Fetch cover art from MusicBrainz Cover Art Archive for albums that have a MB release ID but no cover.jpg sidecar. Saves as cover.jpg alongside the tracks — does not modify audio file tags. Runs in the background.

Missing lyrics

Fetch synced (or plain) lyrics from LRCLIB for every track without a .lrc sidecar. Saves a .lrc file alongside each track — does not modify audio file tags. Navidrome serves these to any Subsonic client (Symfonium, etc.). Runs in the background.
Reset misses clears cached “no lyrics” results so tracks that previously came up empty are looked up again on the next Fetch all.

Tracks without MB ID

Tracks with no MusicBrainz recording ID. Re-enrich to run AcoustID fingerprinting and MB text search — results appear as review suggestions in the Jobs queue.

Low metadata quality tracks Suppressed ↗

Tracks with a low metadata quality score (missing title, artist, album, year, track number, MB ID, or cover art). Press OK in the browse view to suppress the warning if the track is acceptable as-is.

Low bitrate tracks Suppressed ↗

Tracks with bitrate below {{ min_bitrate_kbps }} kbps. Use "Find →" to open the library and replace the source, or press OK to suppress the warning if the bitrate is acceptable.

Trash

Files moved to trash instead of being permanently deleted. Restore to their original location or delete permanently.

Library upkeep

What happens to files after you approve them.

{% call row_choice('compilation_artist_mode', 'On compilations, the track artist is', [('append_to_title', 'Various Artists, performer in the title'), ('album_artist', 'Various Artists'), ('keep', 'the performer')]) %} A 20-track Now That’s What I Call Music credits 20 different performers, and each one Navidrome sees in an ARTIST tag becomes its own one-track artist. The first two options put Various Artists there instead, and the first keeps the performer visible by moving it into the title — Silent Night (Mahalia Jackson). Whatever is replaced is kept in ORIGINALARTIST, so nothing is lost. Applies to tracks acquired from now on; files already in /music keep the tags they have. {% endcall %} {% call row_switch('lyrics_enabled', 'Fetch lyrics') %} On approval, look the track up on LRCLIB and write a .lrc file next to it. Navidrome serves that to any Subsonic client, and audio tags stay untouched. Every track's Edit card can show and change its lyrics. {% endcall %} {% call row_switch('auto_fix_tags_enabled', 'Repair album tags daily') %} Around 04:00, rewrite album, album artist, year, and the canonical MusicBrainz album ID across every album's files.
